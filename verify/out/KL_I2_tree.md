# I2 Digital Media & Items: decided tree

Category line: data-only items held as files, entitlements or tokens: e-books, audiobooks, music and film files, fonts, own photo and video files, in-game and platform items, domain names, NFTs; by kind and file format, never by genre or subject.

Structure: sub-family, then leaf (only where a leaf axis is stated), then kind, then named form (the specific format, typeface family, item design, TLD, token standard or NFT collection; named forms in brackets are examples). Place each object at a kind. Platform, maker, region, genre, subject, rights state (open file, watermark, account-locked, locker licence), unit (track, album, volume, title, episode, season), compression, quality values, licence scope and rarity are never kinds.

## I2.1 Text and document files (read). No leaf. Kind axis: layout form.
- I2-K01 Reflowable e-book file: a book package whose text reflows to the screen [EPUB; MOBI; AZW3; KFX; FB2; .ibook]
- I2-K02 Fixed-layout e-book or document file: a file that keeps a fixed page [PDF; DjVu; Apabi .xeb, .ceb]
- I2-K03 Image-sequence book file: a comic or book held as a packed sequence of page images [CBZ; CBR; CB7; CBT; CBA]
- I2-K04 Plain and rich text file: a bare text or word-processor file with no e-book package [TXT; RTF; DOC; DOCX]
- I2-K05 Digital score file: a music score held as a file

## I2.2 Audio files (heard). Leaf axis: kind of recording.
Leaf: Music recordings
- I2-K06 Digital music file: music held as an audio file [MP3; AAC; Ogg Vorbis; FLAC; ALAC; WMA Lossless; WAV; AIFF; DSD]
Leaf: Spoken-word books
- I2-K07 Audiobook file: a book read aloud, held as a file or file set [M4B; MP3 file set; AA; AAX; AAXC]
Leaf: Podcast episodes
- I2-K08 Podcast episode file: an episode of a podcast held as a file

## I2.3 Moving-image files (watched). No leaf.
- I2-K09 Digital video: film, TV, home video or video artwork held as a file or a locker entitlement [MP4; MOV; MKV; or no file held]

## I2.4 Still-image files (viewed). No leaf. Kind axis: file-format family.
- I2-K10 Camera raw photo file [DNG; NEF; CRW; ARW; IIQ]
- I2-K11 Lossy compressed photo file [JPEG/JFIF]
- I2-K12 Lossless raster image file [TIFF; PNG; JPEG 2000; GIF]
- I2-K13 Layered image file [Photoshop PSD; PSB]
- I2-K14 Vector graphic file [SVG; EPS; AI]

## I2.5 Fonts and production assets (built with). Leaf axis: asset class.
Leaf: Fonts
- I2-K15 Digital font: a typeface family held as font files under a licence [the typeface family]
Leaf: Templates and production packs (kind axis: file kind for the target tool)
- I2-K16 Design template file: a layout file to be filled or adapted [PSDT; AIT; INDT; Canva template; a PSD sold as a template; a PDF sewing or knitting pattern]
- I2-K17 Brush pack: brushes for a drawing or painting program
- I2-K18 Background, texture and frame pack: image materials for use in making other work
- I2-K19 Motion graphics template
- I2-K20 Digital planner: a planner held as a file
Leaf: 3D assets (kind axis: asset part)
- I2-K21 3D model file [OBJ; VRoid avatar model]
- I2-K22 3D material file [MDL]
- I2-K23 3D light file [EXR; HDR]
Leaf: Sound, preset and model assets
- I2-K24 Audio sample pack or instrument library [Kontakt library]
- I2-K25 Preset or LUT pack [Lightroom preset; synth preset]
- I2-K26 MIDI file
- I2-K27 AI model file (model weights held as a file)

## I2.7 Names and tokens (registered). Leaf axis: register.
Leaf: Domain names (kind axis: eligibility class of the TLD)
- I2-K45 Open generic-TLD domain name [.agency; .page; .zone]
- I2-K46 Country-code domain name [.jp; .ai; .az; .pa]
- I2-K47 Eligibility-restricted domain name [CO.JP, AC.JP, ED.JP, GO.JP; sponsored gTLD such as .asia]
Leaf: Tokens (kind axis: token form)
- I2-K48 Unique (1/1) NFT [ERC-721; NFT collections]
- I2-K49 Semi-fungible NFT [ERC-1155; NFT collections]

## Precedence sentences inside I2
1. A file sold as a pack, template, brush, texture, model, preset or sample for making other work is I2.5, whatever its file format; a single image, clip or track held to be looked at, watched or heard is filed by its medium (I2.2, I2.3, I2.4), even when it was licensed as a stock asset.
2. An avatar, outfit or item that is equipped inside a game or platform account is I2.6; the same model held as a file to import into tools is I2.5.
3. A token is I2.7 whatever it depicts or unlocks; its use (art, PFP, game item, membership, domain) is a tag.
4. An e-book package that reflows to the screen (EPUB, Kindle formats, FictionBook, .ibook) is a reflowable e-book file; a file that keeps a fixed page (PDF, DjVu), including a scan saved as PDF or DjVu, is a fixed-layout file; a bare text or word-processor file with no e-book package is a plain and rich text file.
5. A second-level name reserved to a registrant class (CO.JP, AC.JP, ED.JP, GO.JP) and a name in a sponsored or restricted gTLD are eligibility-restricted domain names; other names under a country code are country-code domain names.
6. A photograph, home video or scan held only as a file is I2 whoever made it or is shown; a scan is filed by its file format (TIFF in I2.4; PDF or DjVu fixed-layout in I2.1); a digital artwork file is I2, and a video work held as a file is digital video.
