# DEP_F3_1 report (bullion issues)

Kinds F3.3.01, F3.3.02, F3.3.03 and F3.1.2.01 are all already in data/kinds.tsv, so no kinds file was written (per DEP_COMMON).

Recorded: 73 named forms (F3.3.03 coin programmes 61; F3.3.01 bar designs 7; F3.3.02 rounds 4; F3.1.2.01 1), 4 lines, 8 makers (PAMP Suisse, Valcambi, Argor-Heraeus, Scottsdale Mint, SilverTowne, Golden State Mint, Intaglio Mint, Germania Mint), 43 issuers. Coin programmes are non-maker named forms with notes "issuer I-<slug>;". Bars and the Scottsdale Silver Eagle Stacker round are maker-bound.

Sources: Wikipedia List of bullion coins (main source, full), SD Bullion, Provident Metals, APMEX, BullionByPost, FindBullionPrices, StoneX, Perth Mint brochure and product page, Royal Canadian Mint, Gold&Co. Failed: BullionByPost gold-refiners (301), BullionByPost infopage (403), Jaggards (fetch error). Numista was not reached through search, so no Numista pages were fetched.

Skipped as already stored: Gold Eagle, Gold Buffalo, Gold Maple Leaf, Gold Krugerrand, Gold Britannia, Sovereign, Gold Kangaroo, Gold Swan, Gold Philharmonic, Chinese Gold Panda (silver, platinum and other-country versions written as separate programmes).

Weaknesses: issuer type and country are not filled for government issuers (the Wikipedia list names the country, not the authority, for most). Issuer ids "I-government-of-X" are provisional. Stored NF-F3.3.03-009/-010 still lack their mint (Austrian Mint, China Mint per Gold&Co page). Not covered: Kitco, JM Bullion, Gold Avenue, Heraeus own site, Numista. F3.1.2.01 has only one form, since NCLT coins are mostly covered by other kinds.

Missing kind?: none found; Goldbacks and divisible CombiBar sheets sit in existing kinds.
