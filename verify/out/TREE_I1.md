# I1 Software: decided tree

Category: I1 Software (domain I, Software, Digital & Subscriptions). Membership test: a program or app, or a hosted tool whose value is what the program does for the user (password managers, security and VPN software, operating systems, creative, productivity and finance programs, AI assistants, apps), however it is licensed or delivered (download, subscription, licence key, boxed disc, web), including a separately paid licence or feature unlock for software in a device; a hosted service whose value is the storage, catalogue, connection, place or play it gives access to (cloud storage, email, a streaming catalogue, online play) is I3, even when an app is used to reach it; tried at placement-key step 5, after health and medical software (H2, step 2).

Structure: sub-family (the job the software does for its owner: eleven function sub-families plus one closing parts-and-accessories sub-family), then leaf (the task, material or business function; only where the sub-family has more than about 12 kinds or is opened at depth, otherwise leaf = null), then kind (the generic program type buyers compare). Each object gets one kind. Platform, licence, delivery, plan, edition, version, AI-enablement, market and region are never levels. A kind marked † is named only by the framework key, a review or a decision and needs a fetched page before it enters the data.

Ids (R-58): I1.n is a sub-family and I1.n.m a leaf; a kind is I1.n.m.kk, or I1.n.kk where a sub-family has no leaf.

## I1.1 System and device care

Programs that look after the computer itself: the operating system, its upkeep and its file and remote tools.

Leaf axis: layer of the machine (operating environments, maintenance and recovery, files and remote access).

### I1.1.1 Operating environments

Systems that run the machine and software that hosts other systems.

- I1.1.1.01 Desktop operating system: Operating system that runs a desktop or laptop computer and its applications.
- I1.1.1.02 Virtualisation software: Program that runs one or more virtual machines or whole guest systems on the owner's computer.

### I1.1.2 Maintenance and recovery

Upkeep, clean-up, backup and erasure.

- I1.1.2.01 System cleaner and optimiser: Program that removes junk files and tunes settings to keep a computer clean and fast.
- I1.1.2.02 Uninstaller: Program that removes installed applications together with their leftover files and settings.
- I1.1.2.03 Driver updater: Program that finds out-of-date device drivers and installs newer ones.
- I1.1.2.04 Backup and disk-cloning software: Program that copies files, a disk or a whole system image to the owner's own drives (backup to the provider's servers is a plan, I3).
- I1.1.2.05 Data-erasure software: Program that overwrites storage so that the erased data cannot be recovered.

### I1.1.3 Files and remote access

Archives, discs, remote control, launching and finding files.

- I1.1.3.01 File archiver: Program that packs files into compressed archives and unpacks them.
- I1.1.3.02 Disc-burning software: Program that writes data, audio or disc images to optical discs.
- I1.1.3.03 Remote-desktop software: Program that shows and controls another computer's screen over a network.
- I1.1.3.04 Application launcher: Program that opens applications, files and commands from a typed name or shortcut.
- I1.1.3.05 Desktop search tool: Program that indexes a computer's files and finds them by name or content.
- I1.1.3.06 System utility suite: Bundle of small system tools (window, file, keyboard and settings utilities) sold or distributed as one set, not as a cleaner. †

## I1.2 Security, privacy and identity

Programs that protect the owner, their data and their logins.

No leaf (about 12 kinds or fewer, leaf = null); kind ids carry no leaf part.

- I1.2.01 Antivirus and security suite: Program that protects a computer or phone from malware and online threats; free antivirus, internet-security and total-security editions are one kind.
- I1.2.02 Password manager: Program or hosted tool that stores, generates and fills passwords and logins; family, premium and free plans are variants.
- I1.2.03 VPN service and client: VPN client, with the service it connects to, that encrypts the owner's connection and routes it through a private network.

## I1.3 Office and personal work

Programs for everyday documents, notes, tasks and time.

No leaf (about 12 kinds or fewer, leaf = null); kind ids carry no leaf part.

- I1.3.01 Office suite: Bundle of word-processing, spreadsheet and presentation programs sold as one product.
- I1.3.02 PDF reader and editor: Program that views, annotates, edits, fills or signs PDF files.
- I1.3.03 Note-taking app: App for writing, organising and searching personal notes.
- I1.3.04 Task and project manager: App for listing tasks, tracking their progress and planning projects.
- I1.3.05 Calendar and scheduling app: App for keeping a calendar and scheduling appointments.

## I1.4 Creative production

Programs for making images, video, audio and music.

Leaf axis: medium (images and design; video and animation; audio and music), plus one leaf for an all-apps bundle across media (C14(b)).

### I1.4.1 Images and design

Still images, drawing, design, photos, 3D, fonts and print projects.

- I1.4.1.01 Raster image editor: Program for editing and painting pixel-based images.
- I1.4.1.02 Vector graphics editor: Program for drawing and editing shape-based graphics that scale without loss.
- I1.4.1.03 Graphic design app: Template-driven design app for flyers, social posts, resumes and similar layouts, fitting neither raster nor vector editing alone.
- I1.4.1.04 Photo manager and RAW developer: Program that catalogues, views and develops photographs, including camera RAW files.
- I1.4.1.05 3D modelling software: Program for modelling, sculpting and rendering three-dimensional objects.
- I1.4.1.06 Screenshot tool: Program that captures and annotates what is shown on the screen.
- I1.4.1.07 Font manager: Program that installs, organises and previews fonts.
- I1.4.1.08 Home-publishing software: Program for making cards, calendars, labels and similar printed items at home.
- I1.4.1.09 AI image generator: Program or hosted tool that makes or alters images from a text or image prompt; text-to-image and image-editing modes are one kind (task_mode attribute).

### I1.4.2 Video and animation

Video editing, recording and conversion.

- I1.4.2.01 Video editor: Program for cutting, arranging and finishing video.
- I1.4.2.02 Screen recorder and live-streaming software: Program that records the screen or camera and streams it live; kept as one kind until a source separates the two.
- I1.4.2.03 Video converter: Program that converts video and audio files between formats and settings.

### I1.4.3 Audio and music

Sound editing and music making.

- I1.4.3.01 Audio editor: Program for recording, editing and mastering sound.
- I1.4.3.02 Music-creation and recording software: Program for composing, arranging and recording music.

### I1.4.4 Suites across media

One maker's all-apps creative bundle.

- I1.4.4.01 Creative suite: All-apps bundle of one maker's creative programs, named for no single component; its edition and plan are variants.

## I1.5 Media playback

Programs that play the owner's own media files.

No leaf (about 12 kinds or fewer, leaf = null); kind ids carry no leaf part.

- I1.5.01 Media player: Program that plays video and audio files of many formats.
- I1.5.02 Music player and library manager: Program that plays music and organises the owner's music library.

## I1.6 Money and business

Programs for money and the running of a business, opened at Capterra's headline depth.

Leaf axis: business function (never market: market is a tag). The three leaves are Capterra headline-group names, provisional on the recount of the headline groups; further leaves open at stage-3 harvest.

### I1.6.1 Finance and accounting

Tax, personal finance and accounting.

- I1.6.1.01 Tax-preparation software: Program that prepares and files a tax return.
- I1.6.1.02 Personal-finance manager [家計簿]: Program for tracking accounts, budgets and household money.
- I1.6.1.03 Accounting software: Program for bookkeeping, invoicing and financial reporting for a business or a freelancer.

### I1.6.2 Marketing and sales

Customer and sales tools.

- I1.6.2.01 CRM software: Program for managing customer contacts, deals and sales follow-up.

### I1.6.3 Operations

Day-to-day business operations.

- I1.6.3.01 Point-of-sale software: Program that runs a shop or restaurant till: sales, receipts, stock and payments.

## I1.7 Learning and reference

Programs that teach by method or are a reference work in their own right; the subject taught is never a level.

No leaf (about 12 kinds or fewer, leaf = null); kind ids carry no leaf part.

- I1.7.01 Language-learning software: Interactive program that teaches a language by testing, correcting or adapting to the user's answers.
- I1.7.02 Reference software: Dictionary, encyclopedia or similar reference work delivered as its own program, or on a disc as a program (as an e-book file it is I2).

## I1.8 Development

Programs for building software and running data and servers.

Leaf axis: part of the work (writing code; data and servers).

### I1.8.1 Writing code

Tools for writing and building code.

- I1.8.1.01 Code editor and IDE: Program for writing, running and debugging source code.
- I1.8.1.02 AI coding assistant: Assistant sold or used as a tool that suggests, writes or reviews code.
- I1.8.1.03 Version-control client: Program for tracking and sharing changes to source code.
- I1.8.1.04 Language runtime and compiler: Program that compiles or runs code in a programming language.

### I1.8.2 Data and servers

Databases, servers and network tools.

- I1.8.2.01 Database software: Program that stores, queries and manages structured data.
- I1.8.2.02 SSH and file-transfer client: Program that connects to remote servers by SSH or transfers files by FTP or SFTP.
- I1.8.2.03 Network protocol analyser: Program that captures and inspects network traffic.

## I1.9 Engineering and science

Programs for engineering design, fabrication and scientific work.

No leaf (about 12 kinds or fewer, leaf = null); kind ids carry no leaf part.

- I1.9.01 CAD software: Program for computer-aided design and drafting of parts, buildings and drawings.
- I1.9.02 3D-printing slicer: Program that prepares a 3D model for printing by slicing it into printer instructions.
- I1.9.03 Scientific and analytical software: Program for scientific computation, statistics and data analysis.
- I1.9.04 GIS and earth-mapping software: Program on the owner's machine that edits, analyses or views geographic data (a hosted map or navigation service is I3).

## I1.10 Assistants

AI assistants named by the placement key, by the task a leaderboard ranks.

No leaf (about 12 kinds or fewer, leaf = null); kind ids carry no leaf part.

- I1.10.01 Conversational AI assistant: AI assistant the user talks or writes to for answers, drafting, coding and other general tasks.
- I1.10.02 AI answer and research engine: AI tool that answers questions or researches a topic with cited sources.
- I1.10.03 AI agent platform: AI tool that carries out multi-step tasks on the user's behalf.

## I1.11 Internet access tools

Programs for reaching the internet that are programs in their own right.

No leaf (about 12 kinds or fewer, leaf = null); kind ids carry no leaf part.

- I1.11.01 Web browser: Program for viewing websites.
- I1.11.02 Email client: Program that reads and sends email from a mailbox hosted elsewhere (the mailbox is I3).
- I1.11.03 BitTorrent client: Program that downloads and shares files over the BitTorrent protocol.

## I1.12 Parts and accessories made for one program or device

Add-ons and unlocks made for one program or device (S3: parts follow the whole).

Leaf axis: the host or device the add-on is made for (the one sub-family exempt from the level-1 axis; a leaf with one kind is allowed, R-11).

### I1.12.1 Browser

Add-ons for a web browser.

- I1.12.1.01 Browser extension: Add-on that adds features to one web browser.

### I1.12.2 Code editor or IDE

Add-ons for a code editor or IDE.

- I1.12.2.01 Editor or IDE plug-in: Add-on that adds features to one code editor or development environment.

### I1.12.3 Office or productivity suite

Add-ins for an office or workspace suite.

- I1.12.3.01 Productivity-suite add-in: Add-in that adds features to an office or workspace suite.

### I1.12.4 Audio or graphics host

Plug-ins for an audio or graphics host program.

- I1.12.4.01 Audio plug-in: Plug-in (instrument or effect) that adds sound or image processing to an audio or graphics host program. †

### I1.12.5 Software for one device

Unlocks and companion apps for one device (provisional until one fetched page shows each kind sold).

- I1.12.5.01 Paid feature unlock for built-in device software: Paid unlock or subscription that switches on a function of software built into one device. †
- I1.12.5.02 Device companion app: App that records and shows the readings of one device and does nothing medical; the device's app ecosystem is a ledger row. †

## Precedence inside I1

- An all-apps bundle of one maker's creative programs is the kind I1.4.4.01 Creative suite; a single-app plan is filed under that app's own kind (for example a photo-editing plan under I1.4.1.01 Raster image editor). Its plan, term, seats and edition are variants, never a second home (section 9 sentence 2; section 3 edge object 5).
- A bundle is filed by the component it is named and sold for. Office software sold as a suite is I1.3.01 Office suite; a single program such as a word processor is a component of that suite's named form and is a kind of its own only if it is sold or reviewed alone, as a standalone PDF editor is (I1.3.02 PDF reader and editor) (sections 4b and 9).
- Kinds follow technique inside a medium, not the maker's product list: raster editing is I1.4.1.01, vector drawing I1.4.1.02, a template-driven hosted design tool (flyers, social posts, resumes) I1.4.1.03 Graphic design app. Features inside one program (generative fill, masks) are attributes (section 4b; edge object 1).
- AI is an attribute, not a level. An AI image generator is I1.4.1.09 whatever its input mode (task_mode is an attribute); an AI coding assistant is I1.8.1.02; a general AI assistant that also edits images, writes code and searches the web is I1.10.01 Conversational AI assistant; a tool whose ranked task is answering with sources is I1.10.02, one that carries out multi-step tasks I1.10.03. A code editor that also has AI features stays I1.8.1.01 (sections 3 and 4b; I-1, I-5).
- Antivirus, internet-security and total-security editions are one kind, I1.2.01; a consumer VPN is I1.2.03; a password manager is I1.2.02 on every platform, plan and licence (section 4b).
- Backup software that copies to the owner's own drives (including disk cloning) is I1.1.2.04. A package named and sold as a security or backup program that includes cloud space is I1 (I1.2.01 or I1.1.2.04, by the name it is sold under); a plan whose value is keeping the backup on the provider's servers is I3 (sentence 9, K-71(b)).
- Software that edits or analyses geographic data on the owner's machine is I1.9.04 GIS and earth-mapping software; a map or navigation service is I3 (sentence 10, K-71(c)).
- A program that does the exercise with the user, testing, correcting or adapting to the user's answers, is I1.7.01 Language-learning software; the subject taught is never a level. A library of recorded or streamed lessons is I3 (sentence 8, K-71(a); I-20).
- A dictionary, encyclopedia or other reference work delivered as its own program, or on a disc as a program, is I1.7.02 Reference software; held as a file in an e-book format it is I2 (sentence 13, K-71(i)).
- An email client is I1.11.02 and a web browser I1.11.01; the mailbox and messaging or conferencing services are I3 (sentence 1; K-71(k)). A game launcher or store client and its free account are not filed (sentence 3, K-71(e)).
- A plug-in that adds processing code to a host program is I1 in sub-family I1.12, by its host: browser extension I1.12.1.01, code editor or IDE plug-in I1.12.2.01, office or productivity-suite add-in I1.12.3.01, VST/AU or image-editor filter plug-in I1.12.4.01. A file that a program loads but that adds no executable code (sample library, preset, LUT, MIDI file, AI model weights) is I2 (sentence 12, K-71(h), I-6).
- A paid unlock or subscription that switches on a function of software built into one device is I1.12.5.01. A free companion app that only records and shows the device's readings is I1.12.5.02 Device companion app, and the device's app ecosystem is a ledger row; software that diagnoses, treats or monitors a condition, such as a regulated medical app, is H2, tried before I1 (sentences 6 and 14; K-71(g), R-14, K-37).
- A plan that renews credits is filed as the plan, by what the credits reach (software use is I1, filed by the program's kind); loose credits, tokens and platform currencies are OUT (sentences 7 and 15, K-71(j)).
- Business software is filed by business function (I1.6), with a market tag; an industry-named group (hospitality, healthcare) is not a leaf, and its kinds file by function (section 12, I-4).
- Releases sold under their own name (Windows 95, Office 2024) are named forms of the kind; editions, plans and minor versions are variants (I-21). Software built into a device, and drivers supplied for one device, are part of the device (D1 and the other device categories); software on a disc, floppy or key card is I1 with the carrier as an attribute (sentences 4 and 5).
