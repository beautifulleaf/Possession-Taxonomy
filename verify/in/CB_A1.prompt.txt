BATCH CB_A1. COUNTRY BACKFILL FOR CLOTHING BRANDS (web allowed; no git). Owner rule (BRIEF.md, "Regional coverage of clothing brands"): coverage is counted per country, so every clothing brand needs its country.
Web rules (CLAUDE.md): only WebSearch/WebFetch or mcp__Parallel_Auth__web_search / mcp__Parallel_Auth__web_fetch (allow_live_fetch on); never curl, wget or Python fetching; never build or guess a URL: fetch only URLs from a search result, a row's existing sources, or a fetched page's links. RESUME RULE: append rows as you go; skip maker_ids already in your output. Log fetches in verify/work/CB_A1/fetched.tsv (url, fetch_status, what it gave). Helper files only there.
Input: verify/in/CB_A1_list.tsv (maker_id, name, sources): clothing brands in data/makers.tsv with no country.
For each brand, find a fetched page that states where the brand is based or was founded (its own About page, its Wikipedia article, a company register or a press profile). Country = where the brand is based now (headquarters); if only the founding country is stated, use it and say so in notes.
Output verify/out/CB_A1_makers.tsv with the makers columns of verify/in/HV_COMMON.txt, filling only maker_id, name, country (ISO 3166-1 alpha-2), place (city, when stated), founded (when stated), notes, sources (the page or pages that state the country) and fetch_status (full or partial). Leave every other column empty: the writer merges these rows into the existing ones without erasing anything.
If no page states the country, write no row and list the brand in the report. Report (under 150 words): counts found and not found, and the countries most often added.
