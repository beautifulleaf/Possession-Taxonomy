STAGE 3 COUNTRY BACKFILL FOR WAVE-1 MAKERS (STAGE3_PLAN step 2b; R-98 c; R-101). Web allowed; no git.
Web rules (CLAUDE.md): only WebSearch/WebFetch (the Parallel tools are out of credit); never curl, wget or Python fetching, archives or caches; never build or guess a URL: fetch only URLs from a search result or a fetched page's links. A search excerpt may locate a page but never attests a country; every row needs a page you fetched yourself.
RESUME RULE: append rows as you go; if verify/out/<BATCH>_makers.tsv exists, read it and skip maker_ids already written there or listed in verify/work/<BATCH>/done.tsv (maker_id, result). Log every fetch in verify/work/<BATCH>/fetched.tsv (url, fetch_status full/partial/failed, what it gave). Helper files only in verify/work/<BATCH>/. At load a source missing from the log counts as unfetched and is dropped.
Job: your list (verify/in/<BATCH>_list.tsv: maker_id, name, category, notes, first source) holds makers already in the ledger whose country is empty. For each, find where the maker is based (HQ country, ISO 3166-1 alpha-2), from the maker's own site (about, contact, imprint/impressum, legal notice), a company register or Wikipedia page, or a trade directory entry that states the country. Use the category and notes to be sure the page is about THIS maker (a game studio, a pet-food brand, an optics firm...): a same-name company of another trade is not evidence — skip it and note "homonym only" in done.tsv. A store that ships from a country, a .com domain, or the language of a page is not enough; a stated address, "based in", "founded in <city>" with the company still there, or a register entry is. For a maker whose list notes or first source show it is a brand of a parent, the brand's own base counts (fill parent_id only if a page states the parent and the parent's maker_id exists in data/makers.tsv).
Output verify/out/<BATCH>_makers.tsv (tab-separated, header exactly: maker_id, name, native_name, maker_class, supply_role, country, place, founded, ended, status, parent_id, licensor_id, authority_id, school_ids, extension, notes, sources, fetch_status). One row per maker you resolved; maker_id and name exactly as in the list; country required; place, founded, status when the page states them; other columns empty; notes ≤ 15 words (what the page says, e.g. "imprint: Berlin"); sources = the page(s) showing the country, fetch_status full or partial per source in the same order. Makers you could not resolve after a fair try (two searches, two fetches) go to done.tsv as "not found" with no output row.
Report (under 150 words) to verify/out/<BATCH>_report.md and as your reply: resolved, not found, homonym-only, and countries found (counts).
