# Paste plan for the remaining categories (owner, 2026-10-31)

How to paste: open the page, select all, paste it in a message with the page's web address on the first line, and the category code (e.g. "J3"). One message per page; long pages can be split. Agents treat a paste as a fetched page of that address.

Ranked by value for the effort (top = most brands per paste, or a page no tool can read). Pages are named, not linked: find them on the site named (I don't guess addresses).
