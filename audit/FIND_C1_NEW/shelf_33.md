# Tool storage > Toolboxes, cases & chests
- 205 · Portable toolbox — hand-carried box for tools.
- 206 · Wheeled toolbox (also called: tool trolley) — tool box on wheels with a pull handle.
- 207 · Stackable tool case (also called: modular tool storage system) — case that locks onto other cases of a system by cleats or latches.
- 208 · Tool chest — drawered or lidded top box for tools, set on a bench or roller cabinet.
- 209 · Roller cabinet — drawered cabinet on casters.
- 210 · Site box (also called: jobsite box · site chest) — large lockable steel box for storing tools on site or in a van.
