# Fastening, joining & clamping > Welders & plasma cutters
- 119 · MIG welder — welding machine that feeds a continuous wire electrode through a gun with shielding gas.
- 120 · TIG welder — welding machine using a tungsten electrode and a separate filler rod under shielding gas.
- 121 · stick welder — welding machine that burns coated rod electrodes held in a clamp.
- 122 · multi-process welder — one welding machine set up to run more than one of the MIG, TIG and stick processes.
- 123 · plasma cutter — machine that cuts metal with an electric arc through a constricted gas jet, sold and compared with welders.
