# I2 Digital Media & Items: decided tree

Category line: data-only items held as files, entitlements or tokens: e-books, audiobooks, music and film files, fonts, own photo and video files, in-game and platform items, domain names, NFTs; by kind and file format, never by genre or subject.

Ids (R-58): I2.n is a sub-family and I2.n.m a leaf; the id you give is the kind, I2.n.m.kk, or I2.n.kk where a sub-family has no leaf.

Structure: sub-family, then leaf (only where a leaf axis is stated), then kind, then named form (the specific format, typeface family, item design, TLD, token standard or NFT collection; named forms in brackets are examples). Place each object at a kind. Platform, maker, region, genre, subject, rights state (open file, watermark, account-locked, locker licence), unit (track, album, volume, title, episode, season), compression, quality values, licence scope and rarity are never kinds.

## I2.1 Text and document files (read). No leaf. Kind axis: layout form.
- I2.1.01 Reflowable e-book file: a book package whose text reflows to the screen [EPUB; MOBI; AZW3; KFX; FB2; .ibook]
- I2.1.02 Fixed-layout e-book or document file: a file that keeps a fixed page [PDF; DjVu; Apabi .xeb, .ceb]
- I2.1.03 Image-sequence book file: a comic or book held as a packed sequence of page images [CBZ; CBR; CB7; CBT; CBA]
- I2.1.04 Plain and rich text file: a bare text or word-processor file with no e-book package [TXT; RTF; DOC; DOCX]
- I2.1.05 Digital score file: a music score held as a file

## I2.2 Audio files (heard). Leaf axis: kind of recording.

### I2.2.2 Spoken-word books

- I2.3.01 Digital video: film, TV, home video or video artwork held as a file or a locker entitlement [MP4; MOV; MKV; or no file held]

## Precedence sentences inside I2
1. A file sold as a pack, template, brush, texture, model, preset or sample for making other work is I2.5, whatever its file format; a single image, clip or track held to be looked at, watched or heard is filed by its medium (I2.2, I2.3, I2.4), even when it was licensed as a stock asset.
2. An avatar, outfit or item that is equipped inside a game or platform account is I2.6; the same model held as a file to import into tools is I2.5.
3. A token is I2.7 whatever it depicts or unlocks; its use (art, PFP, game item, membership, domain) is a tag.
4. An e-book package that reflows to the screen (EPUB, Kindle formats, FictionBook, .ibook) is a reflowable e-book file; a file that keeps a fixed page (PDF, DjVu), including a scan saved as PDF or DjVu, is a fixed-layout file; a bare text or word-processor file with no e-book package is a plain and rich text file.
5. A second-level name reserved to a registrant class (CO.JP, AC.JP, ED.JP, GO.JP) and a name in a sponsored or restricted gTLD are eligibility-restricted domain names; other names under a country code are country-code domain names.
6. A photograph, home video or scan held only as a file is I2 whoever made it or is shown; a scan is filed by its file format (TIFF in I2.4; PDF or DjVu fixed-layout in I2.1); a digital artwork file is I2, and a video work held as a file is digital video.
